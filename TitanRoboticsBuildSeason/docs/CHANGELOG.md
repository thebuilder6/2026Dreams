- 2026-09-28 — nav/repulsion-bounds: bounded the APF derivative near contact. The textbook `k * (1/d - 1/d0)` form diverged as `d → 0`; with the previous guards the peer term reached `2.5 * (1/0.05 - 1/1.4) ≈ 48 m/s` and the wall term `2.0 * (1/0.04 - 1/0.65) ≈ 47 m/s`. `MAX_SPEED` hid the magnitude but the commanded *direction* became a near-step function of position at contact, so a robot pressed against a peer saturated and behaved discontinuously. This is the blow-up arXiv:2402.11601 addresses with subharmonic potentials. Floors raised to `REPULSION_MIN_DISTANCE_M` 0.35 (peers) and `WALL_MIN_DISTANCE_M` 0.20 (walls), bounding the terms at ~5.4 and ~6.9 m/s; both floors sit below any behaviourally-relevant distance, so the whole pre-contact curve is bit-identical to the previous one (asserted to 1e-12 across the band). New `repulsiveFalloff(d)` / `wallFalloff(d, margin)` helpers; `SAFE_DISTANCE_METERS` made public so the curve can be pinned by tests. (new `RepulsionBoundsTest` 9/9; `DynamicRouterTest` 8/8 + `StuckRecoveryTest` 8/8 + `PathingQualityTest` 10/10 green, offline) [ARCHITECTURE.md §3A, KNOWN_ISSUES.md §A]

- 2026-09-28 — jev/hysteresis: new `Intelligence/ObjectiveCommitment.java` — per-agent objective latch. The utility matrix is recomputed every 20 ms and several objectives sit within ~0.02 of each other (`SWEEP_ALLIANCE_ZONE` 0.96 vs `CYCLE_SCORE_HUB` 0.72–0.98; `VACUUM_MIDFIELD` 0.35 at batch vs 0.82+ when a piece drifts out of reach), so a loaded bot re-routed every cycle — the reported "constantly moving before trying to shoot".
